- **Major — `docs/LIVE-SESSIONS-DESIGN.md:331`; `codemux-live-session-prompts.md:107`:** Permission requests remain pending indefinitely in the design despite Prompt B requiring configurable deny-on-timeout; specify the flag, default, deadline, cancellation, and late-answer behavior.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:427`; `docs/LIVE-SESSIONS-DESIGN.md:774`; `docs/LIVE-SESSIONS-DESIGN.md:966`:** Mandatory Antigravity lacks an interrupt mechanism, so its per-turn timeout cannot interrupt and continue as specified; require Antigravity in step 4 and define an explicit unsupported-timeout refusal or session-ending fallback.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:323`; `src/result-envelope.ts:335`:** Usage normalization specifies arithmetic but not snapshot accounting, so cumulative totals can be counted twice across turns or resume; define thread-lifetime, invocation, and turn totals with verified baselines and null handling.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:309`; `docs/LIVE-SESSIONS-DESIGN.md:379`:** The promised authoritative author echoes have no specified payload, acknowledgments lack input correlation, and unmapped harness events have no output carrier; define input IDs or line numbers, echoed author/text fields, and a generic raw-event envelope.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:483`:** Putting autonomy flags after `--resume` proves argv construction, not that persisted permissions cannot survive resume; replace the “impossible by construction” claim with a verified effective-policy contract and a high-to-read-only behavioral test.
## 2. Security
- **Blocker — `docs/LIVE-SESSIONS-DESIGN.md:371`; `src/adapters/claude.ts:163`; `src/sandbox.ts:49`:** The ceiling checks only requests reaching the host, while loaded user settings can pre-authorize tools and scode’s writable mode does not prohibit Bash at medium; constrain native pre-approval paths and test a medium session with user settings allowing Bash before claiming an unconditional tool ceiling.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:575`; `src/sandbox.ts:26`:** The registry exclusion assumes codemux constructs every writable root, but codemux supplies scode presets rather than a complete root list; obtain or verify scode’s effective writable policy on each platform, including harness-state redirects and scratch locations.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:515`; `docs/LIVE-SESSIONS-DESIGN.md:583`; `src/hermetic-home.ts:169`:** Creation modes and file ownership checks do not exclude symlinked or writable ancestor directories, so another user could redirect registry reads or replacement writes; specify trusted ancestors, regular-file checks, no-follow opens, and revalidation around atomic replacement.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:398`; `docs/LIVE-SESSIONS-DESIGN.md:477`; `docs/lab-service-features-report.md:917`:** The new contract omits explicit validation that harness-reported session IDs match the requested new or resumed session, recreating the previous wrong-session defect; validate IDs before registration and reject mismatched thread, turn, and permission events before dispatch.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:228`; `docs/LIVE-SESSIONS-DESIGN.md:311`; `src/process-runner.ts:46`:** Bounding only `text` leaves unterminated lines, other fields, raw output, and pending queues unbounded; specify fatal UTF-8 decoding, whole-frame limits, bounded queues, backpressure, and a termination policy that preserves diagnostics without truncating accepted raw events.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:448`; `src/process-runner.ts:111`; `src/process-runner.ts:343`:** A protocol interrupt followed by waiting does not guarantee descendant cleanup, especially if the leader exits first; require descendant capture before shutdown and unconditional tree termination after grace on EOF, signals, timeout, crash, and output-pipe failure.

- **Major — `docs/LIVE-SESSIONS-DESIGN.md:699`; `src/launch.ts:21`; `src/adapters/base.ts:39`:** The plan omits the architectural seam replacing the captured runner, which closes stdin immediately; split transport/lifecycle, immutable session context, adapter translation, permission handling, registry, and CLI into reviewed commits while preserving trusted executable resolution, environment sanitization, validation-before-side-effects, and launcher-owned state.
- **Major — `docs/LIVE-SESSIONS-DESIGN.md:529`; `docs/LIVE-SESSIONS-DESIGN.md:752`:** Registry tests omit lock expiry while a writer remains alive, crash recovery during replacement, byte bounds, registration failure, and pruning active sessions; require those cases and distinguish writer locks from session-lifetime ownership.
