# 2.0.0 detail notes

The complete text of every `[Unreleased]` bullet that the curated
[2.0.0 changelog](https://github.com/bindsch/codemux/blob/main/CHANGELOG.md) summarizes, preserved without change.
The bullets stay grouped under their original headings.

### Breaking

- Pre-launch refusals exit 64 on every command (was 1 on run, tui, check); scripts that tested for 1 must test for 64

### Added

- Add the pre-launch quota gate. `run`, `check`, `tui`, and `session` ask usagemux about the one agent the launch will spend from — after request validation, before anything spawns — and refuse (exit 64, `quota gate: <agent>: …`) when a bounding usage window is below the configured ceiling. New `quota` config key: `minRemainingPercent` (default 10), `weeklyWarnUsedPercent` (default 50, warns on stderr), `timeoutSeconds` (default 15); `quota: false` disables the gate globally. New `--quota-ceiling <percent>` and `--no-quota-gate` flags on all four commands override the config per invocation. Windows whose kind matches `mcp` or `scoped` never gate. A fetched snapshot is reused for 60 seconds per process. An absent, untrusted, timed-out, unparseable, or stale (older than 10 minutes) usagemux warns and proceeds; a provider `error` or `unavailable` status refuses with its message; a status `ok` with no usable window refuses. A refused launch spends nothing and records nothing in the call ledger. The gate is fail-open for unreadable snapshots by design; batch callers keep cmx's strict fail-closed policy.

### Fixed

- Experiment recordings are written only inside a real directory owned by the current user: after creating the recording directory (the state directory's `experiments/` subtree or a spec's `recording`), codemux refuses a symlink at the path and a directory another user owns, and sets the mode to 0700 (previously a pre-existing or linked directory kept its own mode and redirected persistent recordings, the call ledger's rule applied to recordings too).
- A codex hermetic home whose login link fails mid-creation no longer stays on disk: the exit backstop and the tracked-directory registration now happen before the `auth.json` link operations (kimi's ordering), so a failed `linkSync`/`symlinkSync` removes the run directory instead of leaving it for the two-day dead-owner sweep.
- Every spawn re-stats its trust-checked executables (the run and session launch paths, the TUI launch, the scode-wrapped spawn, the experiment MCP server, usagemux, and the Keychain `security` client) and refuses a dev/ino/mode change after the trust check. The residual narrows to the window between that re-stat and the exec itself, still documented in `docs/isolation.md`.
- `bin/codemux` resolves `bun` once from the first absolute PATH entry holding it and execs the absolute path; `.` and relative PATH entries are skipped, and the PATH entry directory, the resolved binary's directory, and the binary itself must be owned by the current user or root and carry no group or world write bit. A planted PATH can no longer choose the runtime.
- The Kimi experiment control probe carries the planted scratch brand home on its control request, so its private `mcp.json` and rewritten `config.toml` land inside the canary scratch by construction; previously only the planted adapter's `KIMI_CODE_HOME` environment kept the writes there. The field is internal and refused on any request that is not a control probe.
- `doctor` probes every installed harness's version in parallel with a 10 s bound per probe (the slowest installed harness, openhands, measured about 6 s; the launch gate keeps 30 s), printing `unreadable (timed out)` for a binary that never answers. The report no longer costs the sum of every binary's startup (about 4.8 s with 14 harnesses installed), and doctor's tests run against fake binaries instead of the machine's real PATH.
- `doctor`'s version-contract verdict distinguishes the two refusals instead of printing `below minimum` for both: a recorded contract break prints `known break at <levels> autonomy from <version> (sandbox mitigates or no mitigation): <note>`, naming the autonomy levels the break affects, while a release under the enforced minimum keeps the old text. The live gate's contract column gets its own `KNOWN-BREAK` verdict with the same detail line, so every surface agrees.
- `codemux usage` human output prints `N% used` when a window reports only a used percent (it printed "remaining unknown"), and rounds every percent to two decimals, matching usagemux's own format. `--json` passes values through and escapes DEL and C1 characters, as `calls --json` does.
- A snapshot whose `windowMinutes` is negative or non-finite parses with `null` instead of failing the whole snapshot; usagemux's protocol puts no positivity constraint on the field.
- `codemux calls --sum` carries `totals cover the newest 16 MiB only` on the totals line itself when the ledger read truncated at its bound, so a script parsing stdout can tell an under-count from the exact sum. The usagemux process deadline grants 5 s of shutdown grace (was 2 s): its discovery and cleanup sit outside its provider timer, and 2 s fired the outer timer on a cold filesystem, turning healthy snapshots into spurious exit 124.
